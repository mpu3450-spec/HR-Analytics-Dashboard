# 📊 HR Analytics Dashboard

An interactive **HR Analytics Dashboard** built using **Power BI, MySQL, SQL, and Python** to analyze employee attrition, workforce demographics, business travel, education fields, and key HR performance indicators.

The project focuses on transforming raw HR data into meaningful insights that can support **data-driven HR decision-making**.

---

## 🎯 Project Objective

The main objective of this project is to analyze employee data and understand workforce patterns, especially **employee attrition**.

The dashboard helps answer questions such as:

- How many employees are currently in the organization?
- What is the overall attrition count and attrition rate?
- Which departments have higher attrition?
- How does business travel relate to attrition?
- Does education field show different attrition patterns?
- Which age groups have higher attrition?
- How does distance from home vary across employees?

## 📂 Dataset

The project uses an HR employee dataset containing information related to:

- Employee demographics
- Age
- Department
- Business Travel
- Education
- Education Field
- Distance From Home
- Employee Number
- Employee Count
- Attrition

The dataset contains **1,470 employee records**.
